# NL4 Poker Trainer

Тренажёр по безлимитному холдему 6-max для микролимитов: настоящая раздача
против пяти ботов, каждый из которых списан с реального соперника из базы
игрока `withorwithout` (7667 раздач на 1win), плюс тренер, который разбирает
каждое решение сразу после того, как оно принято.

Второй модуль к [poker-equity-6max](https://github.com/misuno1985-oss/poker-equity-6max):
оценщик комбинаций, работа с колодой, расчёт эквити, диапазоны и оформление
карт переиспользованы оттуда.

## Состояние

**Этап A — движок раздачи. Готов.**

| Этап | Что входит | Статус |
|---|---|---|
| A | Колода, ставки, банки, улицы, вскрытие | ✅ готов |
| B | 20 профилей ботов, диапазоны, постфлоп-логика | — |
| C | Стол, карты, кнопки, размер ставки | — |
| D | Тренер: оценка решений и объяснения | — |

## Движок

`src/game` — чистый TypeScript: ни React, ни глобальных переменных, ни
`Math.random`. Случайность входит только через seed колоды, поэтому любая
раздача воспроизводится (на этом позже будет построен `REPLAY HAND`).

Деньги везде в **целых центах**. При блайндах 2/4 округление float молча
испортило бы банк.

| Файл | Отвечает за |
|---|---|
| `types.ts` | состояние раздачи, игрок, банк |
| `rng.ts` | seed-генератор, перемешивание |
| `positions.ts` | места ↔ позиции, порядок хода, очередь на нечётный цент |
| `betting.ts` | что легально и что делает действие |
| `pots.ts` | возврат непокрытой ставки, главный банк и сайд-поты |
| `showdown.ts` | сравнение рук, раздача выигрыша |
| `hand.ts` | конечный автомат: раздать → торговля → вскрытие |

Отдельно вынесено самое хрупкое место любого покерного движка — **короткий
олл-ин**. Когда игрок идёт ва-банк на сумму меньше полного рейза, цена растёт,
но торговля **не открывается заново**: те, кто уже ходил, могут только уравнять
или сбросить. За это отвечает флаг `Player.mayRaise`.

## Тесты

```bash
npm install
npm test
```

34 теста. Помимо обычных случаев есть две проверки, ради которых всё и писалось.

**Фаззинг.** 10 000 случайных раздач, случайные легальные действия, 2–6
игроков, стеки от 10 до 250 bb. После каждой раздачи проверяется: фишки не
появились и не исчезли, стеки неотрицательны, сумма результатов равна нулю, ни
одна карта не роздана дважды, при вскрытии на борде ровно пять карт, каждый
банк ушёл сильнейшей руке среди претендентов, сумма банков равна внесённому.

Прогон реально задевает сложные ветки, а не только простые:

```
дошли до вскрытия ....... 6892
выиграны без вскрытия ... 3108
с сайд-потами ........... 3806
с разделом банка ........ 394
хотя бы один олл-ин ..... 6882
```

**Сверка с реальным румом.** `tests/real-pots.json` — все 7667 раздач из
истории игрока, сведённые к тому, что здесь важно: сколько внесло каждое место,
что 1win вернул как непокрытую ставку, сколько выплатил и сколько взял рейка.
Тест прогоняет через наш код 7641 спорную раздачу и требует совпадения до цента.

Расхождение нашлось ровно одно, и оно не про покер: в 26 раздачах деньги внёс
только один игрок — блайнд за столом, который тут же распался, и рум вернул его
без своей обычной пометки «непокрытая ставка». Мы возвращаем те же деньги тому
же игроку; отличается только запись в протоколе. Эти раздачи проверяются
отдельным тестом.

## Что переиспользовано

`src/engine/` скопирован из `poker-equity-6max` без изменений: `cards.ts`,
`evaluator.ts`, `range.ts`, `equity.ts`, `worker.ts`. Кодировка карты там —
`достоинство * 4 + масть` — совпала с кодировкой протокола 1win, поэтому
реальные раздачи из базы попадают в движок без конвертации.

`src/styles/tokens.css` и `src/ui/PlayingCard.tsx` — оттуда же.
